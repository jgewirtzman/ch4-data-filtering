# Agricultural soil, CH4 and N2O (de-identified)

One growing season of soil closures in a managed agricultural grassland, CO2/CH4 on a LI-COR
LI-7810 and N2O on a LI-COR LI-7820 in the same closed loop (1 Hz). Fluxes, model choice,
per-closure-group precision and MDF were computed with goFlux 0.5.0.9002 with additions by the
source project, with the same detection convention as this paper (z = 1.96, closure-median
second-difference precision, t in seconds).

De-identified for this paper: site, plots, collars, experimental treatments and exact dates are
removed (month only) and rows are shuffled. The source data and their experimental context belong
to a separate manuscript in preparation (J. Gewirtzman et al.); release this table only with or
after that paper.
